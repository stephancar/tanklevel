# Tank Level Calculator

Free calculator for horizontal cylindrical tanks: enter diameter, capacity and the measured height to get the remaining litres. The dipstick reading is not linear — this does the circular-segment math for you.

**▶ Use it: https://www.steefware.com/tanklevel/**

Read how it works: [How full is my tank, really?](https://www.steefware.com/blog/tank-level-calculator.html)

## About

- Single self-contained `index.html` — vanilla JS, no build step, no dependencies to install
- No cookies, no ads, no accounts, no tracking; everything runs locally in your browser
- Part of [steefware.com](https://www.steefware.com/), a collection of simple free web tools

## Local development

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```
